Call Centre Dashboard – Excel Analytics Project

*** This project is an interactive Call Centre Dashboard created in Microsoft Excel. The dashboard helps analyze call centre performance using charts, KPIs, pivot tables, and slicers.

## Dataset Used
- <a href="https://github.com/Jeeva93156/Excel-Call-Centre-Dashboard/blob/main/Call%20Centre%20Dashboard/DATASET/Call%20Centre%20Dataset.xlsx">Dataset View</a>

It provides useful insights such as:
*Total Calls
*Answered & Missed Calls
*Agent Performance
*Customer Trends
*Call Resolution Status

-Dashboard <a href="https://github.com/Jeeva93156/Excel-Call-Centre-Dashboard/blob/main/Call%20Centre%20Dashboard/DASHBOARD/Dashboard.png">Dashboard View</a>

This Excel Call Centre Dashboard helps analyze customer service performance using interactive charts, KPIs, and slicers. It provides insights into calls, agent performance, and customer trends in a simple and visual way.

🛠 Tools Used
*Microsoft Excel
*Pivot Tables
*Pivot Charts
*Slicers
*Conditional Formatting
*Excel Formulas


The dashboard helps identify:
*Peak call hours
*Best performing agents
*Call handling efficiency
*Customer service trends
*Answered vs missed calls


This Excel Call Centre Dashboard transforms raw customer support data into clear business insights through interactive visuals and dynamic reports. It helps track call performance, monitor agent productivity, and improve decision-making with an easy-to-use dashboard experience.
